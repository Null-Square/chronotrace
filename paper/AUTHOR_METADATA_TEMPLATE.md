# Author Metadata Template

Do not infer these fields from GitHub usernames, commit emails, or organization names. Complete them explicitly before submission.

## Authors

For each author:

```text
Full publication name:
Affiliation 1:
Affiliation 2 (if any):
ORCID (optional/required by venue):
Email:
Corresponding author? yes/no
```


## Double-blind review audit

Before a double-blind submission:

- replace names with the venue’s anonymous-author format;
- remove acknowledgements/funding that identify authors;
- confirm whether repository links are permitted;
- if repository anonymity is required, create the venue-approved anonymous snapshot without rewriting scientific provenance;
- remove metadata from the compiled PDF if the venue requires it;
- do not remove run IDs/artifact hashes solely because they are inconvenient unless they directly deanonymize the authors and the venue requires anonymization.

## Camera-ready audit

After acceptance:

- restore author names/affiliations;
- add final DOI/venue metadata to `CITATION.cff`;
- archive the exact camera-ready code/result state;
- tag a release corresponding to the paper;
- create an archival DOI (e.g., Zenodo) if desired/allowed;
- retain the development/confirmation provenance files unchanged.
