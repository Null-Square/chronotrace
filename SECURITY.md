# Security

ChronoTrace is a research tool for authorized model auditing and controlled experiments.

Do not open a public issue that contains:

- credentials or API keys;
- private model endpoints;
- confidential training data;
- non-public model weights;
- exploitable security details from a third party.

Report sensitive repository security issues to the NullSquare maintainers through an appropriate private channel.

The project must not embed or publish classified, confidential, or stolen datasets. Validation should use synthetic, licensed, public, or organization-owned material.
